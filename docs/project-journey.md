# Project Journey

The project started as a basic real estate chatbot for answering questions and helping visitors contact a realtor.

It evolved into a multi-workflow lead-capture and operations system with:

1. Intent routing and scenario separation
2. Natural one-question-at-a-time conversation design
3. Email validation
4. Future date-and-time validation
5. Timezone-aware scheduling
6. UTC conversion safeguards in n8n
7. Structured Google Sheets storage
8. Multi-client configuration
9. Request IDs and status tracking
10. False-confirmation prevention

The current result is a working deployment-ready demo that can be adapted to a real estate professional or brokerage.
